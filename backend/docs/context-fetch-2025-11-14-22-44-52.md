## Root Cause Analysis

**Import Chain:**
1. `uvicorn src.main:app` → imports `src/main.py`
2. `src/main.py` line 1 → imports `youtube_utils`
3. `youtube_utils.py` line 14 → imports `Config` from `config.py`
4. `config.py` line 4 → **FAILS** trying to import `OpenAIChatModel` from `pydantic_ai.models.openai`

**The Error:**
```
ImportError: cannot import name 'OpenAIChatModel' from 'pydantic_ai.models.openai'
```

**What This Means:**
- The `pydantic_ai` package is installed (since the import path exists)
- However, `OpenAIChatModel` doesn't exist in `pydantic_ai.models.openai`
- This suggests either:
  1. Wrong import path (API changed in pydantic_ai)
  2. Incompatible pydantic_ai version installed
  3. Class was renamed or moved to different module
