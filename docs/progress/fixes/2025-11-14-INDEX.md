## Key Concepts

### The Architecture Change

**OLD** (Redis/arq):
```
FastAPI → JobQueue (class method) → Redis → arq worker
```

**NEW** (asyncio):
```
FastAPI → JobQueue (wrapper) → LocalJobQueue → asyncio.Queue → Worker coroutines
```

### The API Difference

**OLD**:
```python
await JobQueue.enqueue_job("process_video_task", task_id, url, ...)
```

**NEW** (Wrapper supports both):
```python
from src.workers.tasks import process_video_task
await JobQueue.enqueue_job(process_video_task, task_id, url, ...)
# OR
await JobQueue.enqueue_job("process_video_task", task_id, url, ...)
```
