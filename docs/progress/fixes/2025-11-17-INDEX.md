## Issue Summary

### Issue 1: Clip Duration (7s instead of 10-45s)

**Root Cause:** Validation threshold is 5 seconds, but system prompt says 10 seconds
- Validation: `if duration < 5:`
- Prompt: "MINIMUM 10 seconds"
- Result: AI learns to return 6-8s clips that pass validation

**Fix:** Change validation threshold from 5 to 10 seconds
- **File:** `backend/src/ai_structured.py`
- **Line:** 274
- **Change:** `5` → `10`
- **Risk:** LOW
- **Implementation Time:** 15 minutes

**Evidence:**
```
Groq response duration analysis: avg=8.49s, min=6.80s, max=12.56s
ACCEPTED: Segment 00:49.360-00:57.279 (7.92s, score 0.90)
```

---

### Issue 2: Broken Captions ("EK WE CONTINU")

**Root Cause:** Old cached transcripts bypass word reconstruction feature
- Cache load (line 69-78): Loads immediately, returns early
- Word reconstruction (line 110-128): Only runs if cache doesn't exist
- Cache contains: Broken BPE tokens ("Y", "es" instead of "Yes")
- Result: Captions use broken tokens from cache

**Fix:** Implement cache versioning to invalidate old caches
- **File:** `backend/src/transcription_mlx.py`
- **Changes:** Add cache version constant, check version on load, add version to cache
- **Risk:** MEDIUM (requires cache deletion)
- **Implementation Time:** 30 minutes

**Evidence:**
```
First 10 words from cache: Y, es, ., Y, es, ., U, well, ,, first
Expected: Yes, Yes, Uh, well, ...
Word reconstruction logs: [NONE - never ran due to cache bypass]
```
