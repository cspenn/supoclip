### VUW_LOGO-002: Create Logo Reproduction Script
**Objective:** Create a standalone script to verify that `create_optimized_clip` works correctly when provided with a valid logo path, isolating the issue from the API/Worker layer.
**Files to Modify:**

***Mandatory Pre-Work Checkpoint:***
Use git to make a checkpoint.

**Step-by-Step Instructions:**
1.  Create a new file `backend/tests/reproduce_logo_issue.py`.
2.  Add the following content (adjusting imports as necessary):
    ```python
    import asyncio
    from pathlib import Path
    from src.video_utils import create_optimized_clip
    
    async def test_logo_overlay():
        # Setup paths (assume running from backend dir)
        video_path = Path("tests/fixtures/sample_video.mp4") # Ensure this exists or use a dummy
        logo_path = Path("tests/fixtures/sample_logo.png")   # Ensure this exists
        output_path = Path("tests/output/logo_test.mp4")
        output_path.parent.mkdir(parents=True, exist_ok=True)
        
        # Create dummy files if they don't exist
        if not video_path.exists():
            # Create a dummy video (implementation detail: use moviepy to generate 1s black video)
            from moviepy import ColorClip
            ColorClip(size=(720, 1280), color=(0,0,0), duration=1).write_videofile(str(video_path), fps=24)
            
        if not logo_path.exists():
            from moviepy import ColorClip
            ColorClip(size=(100, 100), color=(255,0,0), duration=1).save_frame(str(logo_path), t=0)

        print(f"Testing with logo_path: {logo_path.absolute()}")
        
        success = create_optimized_clip(
            video_path=video_path,
            start_time=0,
            end_time=1,
            output_path=output_path,
            logo_path=str(logo_path.absolute()),
            logo_position="top-right"
        )
        
        if success:
            print("Clip created successfully.")
        else:
            print("Failed to create clip.")

    if __name__ == "__main__":
        asyncio.run(test_logo_overlay())
    ```
