## 1. Executive Summary

SupoClip presents a **paradox**: static code health is pristine — **466 tests pass, 100% line coverage, ruff clean, mypy clean** — yet the application **does not perform its core function** when actually run. This is not a contradiction; it is the central finding.

**The meta root cause:** the "Clean Consolidation" redesign (React/Next.js → NiceGUI; Playwright → pysubs2/ASS; MoviePy → ffmpeg) was *documented as complete and unit-tested to 100%*, but was executed only at the **module-skeleton level**. Each pipeline stage exists and is individually tested with mocks; the **wiring between stages was never completed or integration-tested**, and nothing enforced end-to-end correctness because the mandated quality gate, `checkpython.sh`, **is a phantom that exists in no document's reality** — not in the working tree, not in git history.

The four most damaging defects are all **wiring gaps between correctly-built parts**, every one invisible to the 100%-coverage test suite:

| # | Defect | Effect |
|---|--------|--------|
| **C-1** | `home.py` builds `ProcessingRequest(subtitle_style=None)`; `clip.py:310` gates *all* subtitle generation behind `if subtitle_style is not None`. `UserPreferences` is never read outside the Settings page. | **Every clip produced from the UI has no burned-in subtitles, no custom font, no styling.** The headline feature and the entire Settings page are dead end-to-end. This is the true source of the "formatting/output issues" complaint. |
| **C-2** | `main.py` never calls `app.add_media_files('/clips/', ...)`. The task page serves clips from `/clips/{filename}`. | **Every clip playback and download returns HTTP 404.** Users cannot view or retrieve any output. |
| **C-3** | The 37 MB / 123-file React/Next.js `frontend/` directory the spec declares "deleted" was never `git rm`'d. | Dead weight; pollutes 32% of the knowledge graph; signals the migration is unfinished. |
| **C-4** | `checkpython.sh` is cited as the MANDATORY pre-commit gate by spec.md, CLAUDE.md, AGENTS.md, qa.md, and rules-python.md — and exists nowhere. | No end-to-end correctness has ever been enforced. Doc-vs-code drift accumulated unchecked. |

**Overall health assessment:** **AMBER-RED.** Engineering fundamentals (typing, error model, async patterns, DB layer) are genuinely strong — see the ✅ sections. But the product is **non-functional for its stated purpose** (produce downloadable captioned vertical clips) and the test suite provides **zero defense against the runtime/output bug class** that actually plagues it. The fix is not just patching the wiring bugs; it is adding a real integration test that produces and inspects an actual `.mp4`, and creating + enforcing the missing quality gate. Without those, the same class of bug recurs.

## 2. Documentation Review Summary

**Promised product (PRD):** self-hosted OpusClip alternative — YouTube/upload input → parakeet-mlx word-level transcription → LLM clip selection (3–7 segments, 10–45s) → 9:16 face-centered crop → word-level ASS subtitles with full style customization → optional logo/transitions → real-time progress → task history + clip management. Single all-Python NiceGUI process, SQLite, `uv`, ffmpeg, port 8008.

**Authoritative baseline:** `docs/spec.md` (1,235 lines) is the most detailed and is treated as authoritative for modules/schema/config; where the PRD contradicts it, spec wins. The docs review surfaced **14 documented contradictions (C1–C14)**, the most material being:

- **C1 (CRITICAL):** `checkpython.sh` phantom gate (cited mandatory in 5 docs, exists nowhere).
- **C5 (HIGH):** `AGENTS.md` is **wholesale stale** — still documents the deleted `backend/` + `frontend/` (Next.js) + `waitlist/` monorepo, `./start.sh`, `npm`, Jest, Python 3.11, and a nonexistent `docs/standards.md`.
- **C6 (HIGH):** `frontend/` still exists despite spec.md:90 stating it was deleted.
- **C7:** PRD promises 3-tier face-detection fallback (MediaPipe → OpenCV DNN → Haar); spec/CLAUDE.md/code mandate MediaPipe-only. PRD line is obsolete.
- **C2/C3/C4:** Python 3.11-vs-3.12 disagreement; three different quality-gate tool lists across three docs; coverage threshold stated as both 100% and `--cov-fail-under=80` within one doc.
- **C11/C12:** mandated `src/exceptions.py` and `src/scripts/` directories absent.

**Conclusion:** there is **no single source of truth**. Documentation describes an aspirational system; the code is a different, partially-wired system; nothing reconciles them.

## 3. Codebase Audit (by emoji category)

### ✅ What's good

Genuinely strong, idiomatic engineering throughout the live modules:

- **Error model (P8, strong):** deliberate domain exception hierarchy (`DownloadError`, `TranscriptionError`, `AnalysisError`, `ClipGenerationError`) with proper `raise … from exc` chaining; `process_video` updates task status to "failed" and re-raises per stage; DB session `rollback(); raise`. No exception swallowing in the hot path.
- **Async & DB layer:** `asyncio.TaskGroup` structured concurrency; `asyncio.to_thread` correctly offloads blocking ffmpeg/yt-dlp/parakeet calls; `get_session()` async context manager with commit/rollback; `expire_on_commit=False`; idempotent `init_db()`; SQLAlchemy 2.0 `Mapped[T]` typing; timezone-aware `datetime.now(UTC)`; cascade delete.
- **Pipeline craft:** BPE token-merge state machine (transcribe) is correct and well-documented; transcript cache versioning (`_CACHE_VERSION = 3`); `filter_words_for_segment` midpoint logic; list-form `subprocess` with `shell=False` and `-ss` before `-i`; `@dataclass(slots=True)` on data structures; `hex_to_bgr_color` / `calculate_margin_v` subtitle math correct.
- **UI:** clean page decomposition; `match-case` over status; structlog used correctly in pages/transcribe/clip/database/main; recently-fixed `sanitize=False` on the preview HTML.
- **Config:** `BaseSettings` + `lru_cache` singleton design (where used); `ClassVar` kept out of env resolution.

### ❌ What's bad

- **`logging` stdlib instead of mandated `structlog`** in `video_service.py`, `analyze.py`, `download.py` (CLAUDE.md explicitly bans it; rest of tree uses structlog).
- **`Config()` directly instantiated** (bypassing the `get_config()` lru-cache singleton) at `analyze.py:364,428,538` and `video_service.py:302` — re-parses `.env` on every pipeline call and defeats test patching.
- **`error_message` column never written** — `_update_task_status` writes `progress_message` instead (`video_service.py:123-124` vs `models.py:72`).
- **Resolution labels disagree with spec** (`clip.py:44-48`: `720p`=720×1280 vs spec 1080×1920).
- **`/tmp` hardcoded for uploads** (`home.py:150`) — violates the explicit project rule and risks mid-pipeline `FileNotFoundError`.
- **Non-YouTube URL stored as `source_type="upload"`** (`home.py:219`) → later treated as a local path → `FileNotFoundError`.
- **Default resolution `1080p`** contradicts spec default `720p` (`home.py:27`).
- **Magic numbers** (`fast`/`23` ffmpeg; `chunk_duration=120`/`overlap=15`; face offset `1.0`; `10_485_760`) — spec bans them.

### ❓ What's missing

- **Subtitle style never wired UI→pipeline** (the C-1 headline).
- **`/clips/` static mount** (the C-2 headline).
- **Logo overlay** — `clip.py:87` "not yet implemented"; `logo_path` threaded but never applied.
- **Transitions** — PRD F8 + `transitions/` dir + `TRANSITIONS_DIR` config exist; `add_transitions`/`transitions_dir` are reserved-for-future no-ops.
- **Karaoke / context-line subtitles** (spec 9.2 differentiator: active word primary + dimmed context via ASS inline tags) — code emits one bare word per event.
- **`@stamina.retry` on the LLM call** (spec 11.5; `download.py` has it, `analyze.py` does not).
- **`InsufficientSegmentsError` and `src/exceptions.py`** hierarchy (spec 12.5).
- **`MAX_WORKERS` concurrency cap, `MAX_VIDEO_DURATION`, `MAX_CLIPS`** and 6 other spec config vars.
- **Multi-frame face aggregation** (spec 4.14: up to 10 frames + median x-center) — code samples 1 frame.
- **`custom_prompt` in the LLM user prompt** (`analyze.py:542` — passed to system prompt only).
- **Upload `accept` filter / max size; home loading `UserPreferences` defaults; status badge on task page; history pagination.**

### 🗑️ What's unnecessary

- Dead `ClipOptions` fields (`logo_path`, `add_transitions`, `transitions_dir`); `clip_order` param never persisted; `words` param in `analyze_transcript`; `get_video_info()` (zero `src/` callers); `Task.title`, `Task.settings_json`, `GeneratedClip.duration` (computed) columns never meaningfully used; `app_port` / `DEFAULT_BACKEND_PORT` (port hardcoded); redundant URL regex patterns 1–7 (pattern 0 is a superset); `get_engine()` (tests only); `_truncate` duplicated across two pages.

### 🛠️ What's fixed (recently, good)

- YouTube Live URL recognition (`a3af789`) + test; local-LLM `base_url` routing (`a3af789`) + test; preview HTML `sanitize=False` (`529be05`); phone-frame preview CSS (`92dfc0f`). **Fix-then-test was followed for the LLM/URL bugs but NOT for the NiceGUI rendering bugs** (untestable under the current stub approach).

### 💥 What's newly broken

- No regressions detected from the recent commits themselves. The "broken" items are **latent from the incomplete migration**, not newly introduced. (See 🤫.)

### 🤫 Silent errors

- **BGR frame passed to RGB-expecting MediaPipe** (`face_detect.py:62`, no `cvtColor`) → degraded detection → faces silently missed → center-crop fallback.
- **cv2-absent fallback returns hardcoded `(1920,1080)`** (`clip.py:392-396`) → portrait source cropped as landscape, no user-visible error. cv2 is an **undeclared transitive dependency** (pinned via mediapipe).
- **ffmpeg filter-path injection** — `ass={path}:fontsdir={dir}` interpolated raw (`clip.py:212-215`); any space/colon/comma in `TEMP_DIR` breaks the filtergraph silently. Spec 10.4 requires escaping.
- **LLM timestamps never bounds-checked vs video duration** (`analyze.py`) → hallucinated `start=300` on a 150s video passes validation → blank/0-byte clip.
- **0-byte download not detected** (`download.py:247`); **all-words-too-short → silent empty subtitle file** (`subtitles.py:157`); **cache load/save failure indistinguishable from "no cache"** → silent expensive re-transcription.
- **`database.py` swallows `ModuleNotFoundError`** on `import src.models` at DEBUG → could silently create a zero-table DB.
- **`get_llm_model()` silently falls back to `openai:gpt-4o`** instead of raising ValueError when misconfigured.
- **DateTime columns lack `timezone=True`** → latent `TypeError` comparing stored (naive on read) vs `now(UTC)` (aware).
- **Async-in-sync-lambda `delete_task`** (`history.py:127`) may no-op depending on NiceGUI version; **fire-and-forget `create_task`** (`home.py:250`) can leave tasks stuck "pending" forever; **no poll timeout** for hung tasks.

### 🐷 Overengineered / overcomplicated

- `suppress(ValueError) + continue` control-flow trick (`analyze.py:468-480`); `_find_fonts_dir` 6-level upward filesystem walk per clip (`clip.py:413`); double-import of `src.pipeline.clip`; redundant URL regex set. Overall, **little gratuitous abstraction** — the error hierarchy and pipeline modules are appropriately lean (P10 PASS).

### 🚮 Tech debt / dead code

- **37 MB `frontend/`** (123 tracked files, 32% of graphify nodes); **phantom `checkpython.sh`**; **`.pre-commit-config.yaml` scoped to nonexistent `^backend/`** (all hooks no-op); **`tests/verify_subtitle_renderer.py`** imports deleted `src.subtitle_renderer.BrowserSubtitleRenderer` + `backend/` path; **`tests/output/logo_test.mp4`** tracked binary; **`supoclip.db`** tracked despite `*.db` ignore; **`.serena/memories/`** 12 tracked files; **`graphify-out/`** 13 MB untracked-but-not-ignored; **stale `AGENTS.md`**; **stub fields / dead exports** (above).

**Quality verdict: quantity without confidence.** The suite is large but provides **no defense against the runtime/output bug class** because:

1. **Every I/O boundary is mocked** — ffmpeg `subprocess`, MediaPipe, the LLM, `asyncio.to_thread`, all NiceGUI widgets. **No test produces or inspects a real `.mp4`, `.ass`, or rendered HTML page.**
2. **"E2E" tests are fully mocked** — `test_pipeline_e2e.py` replaces `_generate_clips_concurrently` (the ffmpeg caller) with `AsyncMock`. `tests/fixtures/sample_video.mp4` (a real 5,441-byte MP4) is committed and referenced by **zero** tests.
3. **Line-only coverage** — 100% line is achievable with half the conditional arms untested.
4. **NiceGUI tests are smoke-only** — `render()` then `assert True`; cannot catch the phone-frame/HTML preview bugs.
5. **The 100% rule actively harms** — it forces tests for dead exports (`get_video_info`) and **codifies broken wiring as correct** (`test_clip.py:342` asserts subtitles are *not* generated when `subtitle_style=None`; `test_video_service.py:138` asserts that None default is correct). The tests pin the C-1 bug in place.
6. **ASS special-char escaping, settings→clip style pipeline, crop-math edge dims** all untested.

**Genuinely good:** the integration DB tests (`test_settings_persistence.py`, `test_pipeline_failures.py`) use a real aiosqlite engine — the correct pattern, which should be extended to ffmpeg.

**Against qa.md success criteria (100% coverage, 100% passing unit, 100% passing real E2E):** unit + line-coverage criteria pass; **the real end-to-end criterion FAILS** — there is no real E2E test.

## 7. Systemic Issues & Root Causes

The synthesis (`output/notes/synthesis.md`) identifies **five root causes**, in priority order:

1. **Wiring gaps, not module bugs.** Parts are tested in isolation; the seams between them are not. → C-1 (subtitles), C-2 (clips 404), O7 (custom_prompt), O9 (error_message).
2. **Over-mocked tests + line-only coverage.** No real artifact is ever produced or inspected, so the entire output-correctness bug class is invisible. → all of Theme 1.
3. **Paper migration.** The redesign was documented "done"; `git rm` was never run; stale config/docs/tests for the deleted architecture remain. → 37 MB frontend, stale AGENTS.md/pre-commit/verify script.
4. **Unenforced phantom gate.** `checkpython.sh` exists nowhere, so nothing runs end-to-end and doc-vs-code drift accumulated unchecked. → 9 missing config vars, status/schema drift, 3-way tool-list disagreement.
5. **Coverage-as-target perversity.** The 100% rule rewards dead-code tests and pins broken wiring as "correct." → reinforces #1, #2, #3.

These are **one cause expressed five ways**: *the migration's skeleton was built and unit-tested, but its nervous system (wiring), immune system (integration tests + gate), and cleanup (dead-code removal) were never finished.*
